## 🤖 TermiGPT — your terminal, assisted by local AI

<a href="https://www.termigpt.tech/"><img src="https://img.shields.io/badge/Explore-TermiGPT-111827?style=flat-square&amp;logo=windows&amp;logoColor=white" alt="TermiGPT" /></a>

**TermiGPT** is a local-first AI terminal assistant designed to help developers translate natural-language requests into commands, troubleshoot errors, and automate shell workflows—without requiring a cloud model for local inference after setup.

```powershell
PS> Create a Python environment and install Flask

TermiGPT plan:
  1. python -m venv .venv
  2. .\.venv\Scripts\Activate.ps1
  3. python -m pip install flask requests
  4. python -c "import flask; print(flask.__version__)"

# Review commands and execution results in the terminal.
```

- 🧠 Local language-model inference, with hardware-dependent GPU/CPU support
- 🛠️ Developer workflows across PowerShell, CMD, WSL, and Git Bash
- ⚙️ Command generation, troubleshooting, and agent-style task execution
- 🧩 Stack: **Electron · React · Vite · TypeScript · Tailwind CSS · local LLMs**

🌐 [www.termigpt.tech](https://www.termigpt.tech/)
